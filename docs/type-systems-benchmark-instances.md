# 类型系统 benchmark：核心定理候选

目录记录 **139 个候选结果**，含审查后退役或合并的条目；正式题集为 100 题。论文来源见[文献索引](type-systems-literature-2017-2026.md)及下表。原有自建任务、难度和 feature 变体不计入。

这里的一个 instance 是一个实质性的目标定理。源码把同一个安全性或对应性目标拆成几个声明时，在同一行注明，不按声明数计。一个证明的包装、直接推论，以及同一篇论文给的简化版和扩展版，不因数量要求拆开。同一篇论文可保留不同的核心证明，例如 McTT 的 NbE 可靠性和完备性分别依赖不同的语义模型和 fundamental proof，故各计一个。

下表记录论文结论与对应的 Rocq 声明；实际通过题面检查的条目见[题目目录](../benchmarks/research-pilot/)。入库时要检查目标是否能通过现成的同义定理或短包装跳过核心工作。同一项目或系统家族的任务应一起报告，不能当作相互独立的样本。
